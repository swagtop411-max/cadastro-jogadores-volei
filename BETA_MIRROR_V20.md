# Beta Mirror V20

A Beta pública não possui layout próprio.

`teste-social.html` apenas ativa a flag local de teste e redireciona imediatamente para `/index.html?beta=1`.

Consequências:
- mesmo HTML do app principal;
- mesmos CSS e componentes;
- mesmas imagens e assets;
- mesmo feed, perfis, comunidade, reels, salvos e navegação;
- mesmas correções e evoluções futuras do app principal;
- nenhuma duplicação visual para manter.

A única diferença visível no modo Beta é um pequeno botão flutuante `BETA`, que abre ações de instalação PWA e envio de feedback. Ele não altera o layout principal.
